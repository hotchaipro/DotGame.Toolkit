# Security

DotGame.Toolkit loads content and input that may come from anywhere, so a file or input that makes it crash, hang,
read or write outside its buffers, or use far more memory than its size suggests is a security problem.

Please report one privately, not in a public issue: use GitHub's private vulnerability reporting for this
repository (the Security tab, "Report a vulnerability"). Include what causes it, if you can.

Fixes go into the latest version only.
